# 明日方舟丝卡蒂桌宠 - 项目概览

## 项目简介
这是一个基于PyQt5开发的桌面宠物应用，以明日方舟角色"丝卡蒂"为主角。项目最初在GPT技术普及前开发，目前正在进行现代化改造，计划集成GPT等AI功能。

## 核心功能
- **桌面宠物显示**: 透明窗口的丝卡蒂角色动画，支持多种状态（待机、移动、交互、攻击等）
- **交互系统**: 鼠标点击、拖拽、长按等交互方式
- **对话事件**: 基于flag的事件管理系统，支持条件对话和选项分支
- **情感系统**: 角色情感状态管理（普通、惊讶、愤怒、失落等）
- **动画系统**: PNG序列帧动画播放，支持多种动作状态

## 技术架构

### 主要组件
- **main.py**: 应用程序入口，创建桌面宠物主窗口
- **character.py**: 角色类，继承自精灵类，管理角色状态和事件
- **sprite.py**: 精灵基类，处理动画显示和用户交互
- **dialog.py**: 对话框组件，显示事件对话和选项
- **event_manager.py**: 事件管理器，处理事件逻辑和flag系统
- **animation.py**: 动画播放器，处理PNG序列帧动画
- **state_manager.py**: 状态管理器（待完善）

### 资源结构
```
asset/
├── gui/               # 界面资源
│   ├── index.png      # 托盘图标
│   └── close.png      # 关闭图标
└── sprite/
    └── sikadi_blue/   # 丝卡蒂角色资源
        ├── Images/    # 动作序列帧
        │   ├── Idle/      # 待机动画
        │   ├── Move/      # 移动动画
        │   ├── Attack/    # 攻击动画
        │   ├── Interact/  # 交互动画
        │   ├── Sit/       # 坐下动画
        │   ├── Start/     # 启动动画
        │   └── Loss/      # 失败动画
        ├── Emotions/  # 情感图标
        └── Events/     # 事件配置文件
```

### 事件系统
项目采用基于flag的事件驱动系统：
- **事件触发条件**: 通过flag数组定义前置条件
- **事件流程**: 内容显示 → 动作执行 → 选项选择 → flag更新 → 下一个事件
- **事件类型**: 支持随机事件和条件事件

## 使用说明
1. 安装依赖：`pip install -r requirements.txt`
2. 运行主程序：`python main.py`
3. 通过系统托盘图标控制应用
4. 点击宠物进行交互，拖拽移动位置

## 配置文件
- **achieves/sikadi_blue.json**: 角色成就和flag数据
- **asset/sprite/sikadi_blue/Events/*.json**: 事件配置文件
- **requirements.txt**: Python依赖包列表
